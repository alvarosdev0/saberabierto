# questionnaire-builder Specification

## Purpose

At the end of a study session, the user creates exam-style questions — either written manually or imported from AI-generated questions. Each question is linked to its source section and saved to Dexie for spaced retrieval.

## Requirements

### Requirement: Question Creation

The system MUST allow the user to write exam-style questions with guidance text displayed: "Forza la elaboración, opinión o aplicación a contextos nuevos."

#### Scenario: Create manual questions
- GIVEN the user has completed a session with 2 sections
- WHEN they open the questionnaire builder and write two questions, each linked to a different section
- THEN both questions are saved to Dexie with their source section IDs

#### Scenario: Empty question rejected
- GIVEN the questionnaire builder form
- WHEN the user taps "Guardar" with an empty question field
- THEN the system shows: "Escribe al menos una pregunta."
- AND nothing is persisted

### Requirement: AI-Generated Question Import

The system MUST allow the user to import questions previously generated by the AI question generator into the questionnaire. Imported questions are tagged with `source: 'ai'` and optional `sourceProvider` (e.g., `'openai'`).

#### Scenario: Import AI questions
- GIVEN AI has generated 5 questions for "Sección 2"
- WHEN the user selects 3 of them and taps "Importar al cuestionario"
- THEN those 3 questions are copied into the questionnaire with `source: 'ai'`
- AND the original AI-generated questions remain available

#### Scenario: No AI questions available
- GIVEN no AI questions have been generated for any section
- WHEN the user opens the questionnaire builder
- THEN the "Importar de IA" option is disabled with tooltip: "Genera preguntas con IA primero"

### Requirement: Import from Reading Questions

The system MUST allow the user to import questions written during the interrogative reading phase into the end-of-session questionnaire. Imported questions are tagged with `source: 'manual'`.

#### Scenario: Import reading questions
- GIVEN the user wrote 4 questions during interrogative reading across 2 sections
- WHEN they open the questionnaire builder and tap "Importar de preguntas de lectura"
- THEN the 4 questions are listed with their source sections
- AND the user can select which ones to import into the questionnaire
- AND imported questions are tagged with `source: 'manual'`

#### Scenario: No reading questions available
- GIVEN the user wrote no questions during interrogative reading
- WHEN they open the questionnaire builder
- THEN the "Importar de preguntas de lectura" option is disabled with tooltip: "Escribe preguntas durante la lectura primero"

### Requirement: Source Section Linking

Every questionnaire question MUST be linked to the section it was created for. The `questionnaireItems.source` field is `'manual' | 'ai'` with optional `sourceProvider` for AI-generated questions.

#### Scenario: Link to section
- GIVEN a session with sections "Capítulo 1" and "Capítulo 2"
- WHEN the user creates a question and selects "Capítulo 1" as the source
- THEN the question's `sectionId` references "Capítulo 1" and `source` is set to `'manual'`
- AND the spaced-retrieval system can later group reviews by section
